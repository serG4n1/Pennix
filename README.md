# Pennix для Linux (X11 + System Tray)

Продвинутый аналог **Hiddex** («Boss Key») под Linux, поддерживающий сокрытие **как окон приложений, так и их иконок в системном трее** (StatusNotifierItem / XApp / AppIndicator).

## 🌟 Ключевые возможности

1. **Два режима выбора скрытия**:
   - **📱 По приложениям**: классическая группировка по классам окон (скрывает все окна выбранной программы сразу).
   - **🪟 По окнам / процессам**: детальный выбор конкретных окон по их заголовкам, XID и PID процесса (удобно, когда нужно скрыть отдельное окно браузера, терминал или документ, не трогая остальные).

2. **Поддержка системного трея (StatusNotifierItem / XApp / AppIndicator)**:
   - Обнаруживает приложения, работающие в фоне и свернутые в трей (например, **Telegram**, **Discord**, **Steam**, **Clash Verge**), даже если их графическое окно закрыто!
   - Отображает их в списке с оригинальными значками и пометкой `🔔 трей`.

3. **Мгновенное скрытие и возврат без закрытия процессов**:
   - При нажатии горячей клавиши окно исчезает с экрана, с панели задач и из переключателя `Alt+Tab` (через ICCCM withdraw).
   - Иконка из трея также исчезает.
   - Сам процесс приложения, сеть и фоновые соединения **не прерываются**.
   - При повторном нажатии хоткея всё мгновенно возвращается на свои места.

4. **Глобальные горячие клавиши**:
   - Работают отовсюду в фоновом режиме (по умолчанию `Ctrl + Alt + Q`).
   - Назначаются в один клик через удобный интерфейс с интерактивным перехватом клавиш.

5. **Сокрытие окна самого Pennix**:
   - Опция «🔒 Скрывать и само окно Pennix» включена по умолчанию — Pennix бесследно растворяется вместе со всеми выбранными объектами.

## 🚀 Установка и запуск

### 1. Сборка из исходников

Для сборки требуется компилятор Rust (`cargo`) и стандартные библиотеки X11.

```bash
# Клонирование репозитория
git clone https://github.com/serG4n1/pennix.git
cd pennix

# Сборка оптимизированного релиза
cargo build --release
```

Готовый бинарник будет лежать в `target/release/pennix-linux`.

### 2. Установка в систему (в меню приложений)

Чтобы запускать Pennix командой `pennix` из терминала или через меню приложений (с иконкой):

```bash
# Копируем бинарник в пользовательскую директорию bin
mkdir -p ~/.local/bin
cp target/release/pennix-linux ~/.local/bin/pennix
chmod +x ~/.local/bin/pennix

# Устанавливаем иконку
mkdir -p ~/.local/share/icons/hicolor/256x256/apps
cp assets/pennix.png ~/.local/share/icons/hicolor/256x256/apps/pennix.png

# Устанавливаем .desktop файл
mkdir -p ~/.local/share/applications
cp assets/pennix.desktop ~/.local/share/applications/pennix.desktop
update-desktop-database ~/.local/share/applications 2>/dev/null || true
```

## ⚙️ Системные требования

- **ОС**: Linux
- **Графический сеанс**: X11 (на Wayland сокрытие работает для приложений XWayland и иконок трея).
- **Окружения рабочего стола**: GNOME, KDE Plasma, Cinnamon, XFCE, MATE и др.
